BKTI DESIGN RULES — Quy tắc thiết kế giao diện

[1] COLOR PALETTE
    Primary:       #998fc7 (Tím lavender chính)
    Primary Hover: #8578b8
    Primary Light: #e2dcfc (Badge, highlight nhẹ)
    Accent:        #7b61ff (Link, điểm nhấn, score)
    Accent Dark:   #554880 (Hover link)
    Card BG:       #ffffff
    Card Inner BG: #fcfbfe (Nền phụ bên trong card)
    Text Primary:  #000000
    Text Body:     #333333
    Text Muted:    #666666
    Border Subtle: rgba(153,143,199, 0.2)
    Border Medium: rgba(153,143,199, 0.3)
    Card Shadow:   1px 4px 21.2px rgba(153,143,199, 0.41)
    Gradient BG:   252deg, #f9f8fb → #ebddff

[2] TYPOGRAPHY
    Font Family: "Inter", sans-serif
    Weight Map:  Light=300, Regular=400, Medium=500, SemiBold=600, Bold=700
    ⚠ KHÔNG dùng "Inter-SemiBold", "Inter-Bold"... → dùng "Inter" + font-weight

    Heading XL:  32px / 600  (Intro heading)
    Heading LG:  26px / 700  (Credit title)
    Heading MD:  24px / 600  (Block title desktop)
    Heading SM:  20px / 600  (Section title, ranking group)
    Body:        15px / 500  (Paragraph desktop)
    Body SM:     14px / 500  (Paragraph mobile, subtitle)
    Caption:     13px / 600  (Indicator, quote)
    Label:       10px / 300  (Ranking light text)

    Mobile Scale: Heading MD → 20px, Heading SM → 18px, Body → 14px

[3] SPACING (8px grid)
    4px | 8px | 12px | 16px | 20px | 24px | 32px | 40px

[4] CARD STYLE
    Border Radius:      25px (desktop) | 15px (mobile)
    Inner Card Radius:  16px (desktop) | 12px (mobile)
    Padding Desktop:    25px 35px (intro) | 32px 40px (credit) | tùy khối
    Padding Mobile:     24px 16px (chung)
    Shadow:             1px 4px 21.2px rgba(153,143,199, 0.41)

[5] BUTTON STYLE
    Height:       50px (desktop) | 48px (mobile)
    Border Radius: 25px (desktop) | 24px (mobile)
    Primary BG:   #998fc7 → hover #8578b8
    Primary Shadow: 0 4px 15px rgba(153,143,199, 0.35)
    Secondary:    #ffffff, border 1px solid rgba(153,143,199, 0.3)
    Transition:   all 0.25s cubic-bezier(0.25, 1, 0.5, 1)
    Hover:        translateY(-2px)
    Active:       translateY(1px) scale(0.98)

[6] RANKING BADGE (Ellipse)
    Size:          40px (desktop) | 32px (mobile)
    Rank 1:        gradient #ffd700 → #ffb300, shadow gold
    Rank 2:        gradient #e0e0e0 → #9e9e9e, shadow grey
    Rank 3:        gradient #d7ccc8 → #8d6e63, shadow brown
    Rank 4-10:     bg #e2dcfc, color #7b61ff, border subtle

[7] BREAKPOINTS
    Desktop:  > 992px   (absolute layout, max-width 1440px)
    Tablet:   769–992px (flex layout, 2-column hoặc single)
    Mobile:   ≤ 768px   (flex layout, single column)

[8] ANIMATION
    Slide Fade In: 0.35s ease-out, translateY(10px) → 0
    Slide LR:      0.35s cubic-bezier(0.25, 1, 0.5, 1), translateX(±40px) → 0
    Overlay:       0.3s ease-in-out, blur 0→4px

[9] LAYOUT RULES
    - Mỗi card (khối nội dung) phải tự chứa title + content bên trong.
    - Không đặt title ở position: absolute ngoài card parent.
    - Desktop: absolute positioning cho macro-layout.
    - Mobile: flex column, order-based reflow.
    - Max content width desktop: 971px (khối intro) | 968px (khối fullwidth).
    - Mobile max card width: 580px, căn giữa.

[10] RESPONSIVE RULES
    - Ẩn card-rect decorative trên mobile.
    - Card wrapper tự tạo background, radius, shadow trên mobile.
    - Spacing mobile thu hẹp: padding 24px 16px, gap 16px.
    - Font scale giảm ~2-4px so với desktop.
    - Ranking progress bar ẩn trên mobile, chỉ hiện score text.
    - Hiển thị đầy đủ tất cả các khối nội dung trên mọi breakpoint.

[11] CSS VARIABLE NAMING
    Color:     --color-{role}          (vd: --color-primary, --color-text-body)
    Font Size: --fs-{scale}            (vd: --fs-heading-md, --fs-body)
    Font Wt:   --fw-{name}             (vd: --fw-semibold)
    Spacing:   --sp-{value}            (vd: --sp-16)
    Card:      --card-{property}       (vd: --card-radius, --card-padding-mobile)
    Transition:--transition-{speed}    (vd: --transition-default)
